Built with Modern Tech

A full-stack, enterprise-grade architecture providing rapid music streaming and responsive client apps.

Flutter & Dart

Powers the multiplatform client application, using Provider for state management and high-performance audio players.

Spring Boot

Robust Java backend handling REST APIs, JSON data serving, user profiles, and secure authorization filters.

PostgreSQL

Relational database holding users, song info, likes, and relational tables for per-user custom soft deletes.

Cloudinary

Globally distributed media CDN hosting the album artwork and actual high-quality MP3 audio files.
